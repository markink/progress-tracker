Pet-проект: Progress Tracker

Этот сайт — мой личный проект, созданный для практики современных технологий и демонстрации навыков системного аналитика в реальном продукте. Он развёрнут на собственном сервере под управлением Ubuntu, полностью контейнеризирован и описан как код — переезд на новый сервер занимает одну команду.

Что умеет

  • REST API с автогенерацией документации в Swagger UI (OpenAPI 3.1)
  • Хранение журнала прогресса в PostgreSQL — транзакционные данные
  • Хранение динамического каталога навыков в MongoDB — polyglot persistence
  • Reverse-proxy на Nginx с автоматическим SSL от Let's Encrypt
  • Полная контейнеризация через Docker Compose
  • Bootstrap-скрипт для развёртывания с нуля за одну команду
